# Therapeutic Concept Coverage Audit

Date: 2026-10-12

## Purpose

This audit checks whether the initial graph vocabulary represents the explicit concepts in the existing Mental, Emotional, and Physical sections. It is intentionally separate from the source-content audit: a page can preserve all therapeutic prose while still having incomplete graph indexing.

## Current Finding

The first concept pass created a useful seed vocabulary and reciprocal navigation, but it was not exhaustive. Amazonite has since been reconciled through the sentence-level register; the remaining rows below are the historical cross-page inventory for pages that have not yet completed that workflow. Link count is not used as a completeness measure.

## Execution Rule

The same register-first workflow is now the required standard for the next gemstone. Each candidate receives a final state of `mapped`, `intentionally unmapped`, or `blocked`; no gemstone is marked concept-complete on link count alone.
